# 便签双栏切换功能实现计划

## Context

z-note 是 Python Tkinter 单文件应用（`main.py` ~3660 行 + `storage.py` JSON 持久化），整个便签页建立在一个 `tk.Text` 编辑器上（body canvas 承载、覆盖层复选框/删除线、分块滚动缓冲、IME、撤销栈）。用户要求在工具栏**删除键左边**加一个 `columns-2` 图标按钮，点击后当前便签变为左右两栏：

- 已有内容留在左栏，右栏初始为空
- 中间隔条：圆润、不粗、灰色、上下不顶满页面
- 每栏逻辑与普通便签页完全一致（文字/待办/勾选/类型转换/撤销/粘贴/滚动）
- 清除已完成沿用现有逻辑（覆盖两栏）
- 回收站（历史窗口的已删除便签预览）同样按两栏展示
- 切回单栏时右栏内容**合并到左栏底部**（已确认）
- 切成两栏时窗口**自动加宽到约 1.8 倍**（不超过屏幕工作区），切回不缩窄（已确认）
- 双栏状态按便签持久化

## 数据模型（无 schema 变更，JSON 宽松）

- `d["twoColumn"]`: bool，启动时对 notes/deletedNotes `setdefault(False)`（模式同 `main.py:3227-3228` 的 editedAt 迁移）
- `d["lines"]` = 左栏；`d["lines2"]` = 右栏（切双栏时创建 `[{"type":"text","text":"","checked":False}]`，切回时删除）
- 现有读 `d["lines"]` 的代码（左栏）天然兼容

## 改动清单

### 1. 图标资产 `assets/icons/`
- 生成 `columns-2-normal.png` / `columns-2-active.png`（64px，#4B5563 / #1F2328，笔画按 Lucide 2/24 比例、圆头圆角矩形+中缝竖线）：环境有 cairosvg 就栅格化官方 SVG（已下载在 viz 目录），否则 PIL 直接画（图形极简单）
- 拷贝官方 `columns-2.svg` 入目录，更新 `assets/icons/README.md`

### 2. `ToolButton` 激活态（main.py:391）
把 `"columns-2"` 加入 active 图标集合（与 pin、arrow-down-to-line 同款深色激活图）。

### 3. 工具栏按钮（main.py:615 之后）
```python
btn("columns-2", lambda: "切回单栏" if self.d.get("twoColumn") else "切换双栏", self.toggle_columns).pack(side="right", padx=5, pady=9)
```
pack 在 trash 之后 side=right → 落位删除键左边。`_tool_btns` 自动参与 `_title_max_width()`（main.py:1524-1530），标题胶囊自动避让。

### 4. 抽取 `NoteEditor` 类（核心工作量）
把编辑器状态+方法从 `NoteWindow` 原样搬入新类，NoteWindow 持有 `self.editors = [e0]` 或 `[e0, e1]`：

- **移入状态**：text、body、scroll_thumb、done_font、`_check_images/_check_slots`、`_row_layout`、`_chunk_start`、`_document_height`、`_content_height`、`_buffer_margin`、`_body_region`、`_strike_widgets`、`_selection_masks`、`_checkbox_widgets`、`_edit_history/_edit_redo`、IME/滚动 job、`_edge_fade`
- **移入方法**（大体逐字搬运）：`_make_check_images`(989)、`render`(1601)、`_layout_text`(1269-1428)、`_sync_lines_from_text`(1790)、`_text_scrolled`(835)、`_text_wheel/_stop_wheel`、`_scroll_to/_body_index`、`_draw_strikes/_queue_strikes`、`_paint_selection`、`_remember_edit`+undo/redo、按键/IME 处理、`toggle_done`(2032)、`convert_rows`(2042)、`_clamp_todo_cursor`、剪切/复制/粘贴、add_todo 插入逻辑
- lines 访问改为 `editor.lines` property（col 0 ↔ `win.d["lines"]`，col 1 ↔ `win.d["lines2"]`），写入时同步 `editedAt`
- 每栏各一个 `VerticalThumb` 放各自栏内右缘；点击栏即聚焦；添加待办/Ctrl+Z 作用于聚焦栏
- 窗口级代码（标题/拖动/缩放/透明度/置顶/底栏）留在 NoteWindow 不动

### 5. `toggle_columns()` 新方法
- 单→双：`twoColumn=True`、`lines2` 置空行、创建第二编辑器、`w = min(round(w*1.8), 屏幕工作区宽)`（x 必要时左移防出屏）、重布局、按钮 `set_active(True)`、`schedule_save`
- 双→单：先 sync 两栏 → 右栏非空行追加到左栏末尾 → 拆第二编辑器、删 `twoColumn/lines2`、宽度不动、保存（非破坏操作，不走 `_store_history`）

### 6. `_relayout/_layout_footer`（main.py:774-833）
- 双栏时 body 区横向均分：每栏宽 = (可用宽 − 14px 间隔)//2
- 隔条：窄 `tk.Canvas` 画竖向圆头线（宽约 4-5px，灰 #D8DCE1，上下各留 ~14px 不顶满）
- 双栏模式最小宽 520（每栏 ≥ ~240），单栏维持 280

### 7. 状态与清除已完成
- `update_status`(1645)：两栏 todo 合计统计
- `App.archive_done`(3363-3381)：对 `lines` 与 `lines2` 各执行现有逻辑，归档条目加 `"col"` 字段（旧数据无 col 按 0）；`return_archive` 按 col 放回对应栏（实现时先读 3407+ 确认现有恢复逻辑）

### 8. 回收站预览 `HistoryWindow`（main.py:3169-3216）
deletedNotes 模式下若 `note.get("twoColumn")`：preview 区左右两列并排渲染 `lines`/`lines2`（复用 `preview_line`），中间加同款灰色隔条。

## 验证（手动清单，GUI 应用）

1. 点新图标 → 变两栏、自动加宽、隔条符合描述、原内容在左栏
2. 两栏各自：打字/加待办/勾选/右键转类型/Ctrl+Z 撤销/粘贴多行/独立滚动
3. 清除已完成 → 两栏已完成项都归档，清除记录可见、可还原回正确栏
4. 切回单栏 → 右栏内容接在左栏底部，不丢内容
5. 删除便签 → 回收站预览两栏并排；还原后仍是两栏
6. 重启应用 → 双栏状态保持
7. 单栏便签全部行为与改前一致（回归）
8. 图标 22px 观感与旁边三个按钮一致（同 hover 圆底）
