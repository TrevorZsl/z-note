# 一键复制整张便签（正文右键菜单）

## Context

换设备前，需要把一张便签的全部内容一次复制走；贴到应用内另一张便签时，要像现在的复制一样认得待办和文字。

现状（`main.py`）：
- 复制只有 Ctrl+C，作用于选区、单栏，标题不参与。
- 「哪行是待办、有没有勾选」只记在进程内存 `app._clipboard_lines`（`main.py:2681`），粘贴时按「剪贴板序号 + 文字」比对命中（`main.py:2694`）。

你已确认的三项决定：入口只放正文右键菜单；剪贴板内容是纯文字、不带标记；只复制正文、不带标题。

由此得到的结果与边界：
- **本次运行内**贴到任意便签：待办、勾选状态原样还原，行为与现在的复制一致。
- **换设备或重启后**贴回 z-note：是纯文字，待办变成普通文字行。可用现有的「全选 → 右键 → 全部转为待办」整批转回（`convert_rows`，`main.py:3017`），勾选状态需要重勾。

## 改动

只动 2 个文件，粘贴一侧零改动。

### 1. `main.py` — 新增 `NoteWindow.copy_all()`
放在 `NoteWindow` 的「编辑事件」区（`clear_done` 之前，`main.py:4078` 附近）。

- 先调 `self._sync_lines_from_text()`（`main.py:3359`），把两栏尚未同步的输入落进模型。写法与 `archive_done`（`main.py:7862`）一致。
- 取行：`("lines", "lines2") if self.d.get("twoColumn") else ("lines",)`，左栏在前、右栏在后（同 `main.py:7863`）。
- 每行只保留 `type / text / checked`，丢掉折叠双栏留下的临时键 `mergedColumn`，避免贴到别的便签后串栏。
- 所有行都为空时直接返回，不覆盖剪贴板。
- 剪贴板写入 `"\n".join(各行文字)`，与现在「全选 → Ctrl+C」得到的文字相同。
- 写 `self.app._clipboard_lines = (user32.GetClipboardSequenceNumber(), content, lines)`，格式同 `main.py:2681`。

应用内粘贴因此直接命中现有结构化路径 `_paste_lines`（`main.py:2697`）：待办还原、选区替换、前后文字衔接、撤销/重做全部沿用。

### 2. `main.py` — 正文右键菜单加第四项（`_on_rightclick`，`main.py:2999`）
`actions` 末尾追加 `("复制全部内容", self.win.copy_all)`。

```
转为待办                 Ctrl+Shift+L
在下方插入新行
──────────────────────────────
删除此行
──────────────────────────────
复制全部内容          ← 新增
```

追加在最后，前三项位置不变，现有按序号取第 0、第 2 项的断言（`test_note_editing.py:3740`、`:3766`、`:5284` 等）不受影响。

### 3. `main.py` — 自绘菜单支持第四行（`_show_context_menu`，`main.py:3994`）
现在写死三行：只有第 3 项下移 9px，分隔线固定画在第 2 项之后。改成按项数计算：

- 第 3 项起每跨一组下移 9px：`top = 8 + i * row_h + 9 * max(0, i - 1)`
- 高度：`16 + row_h * len(actions) + 9 * max(0, len(actions) - 2)`
- 分隔线在第 2 项、第 3 项之后各一条，后面没有项时不画

三行菜单的高度与分隔线位置和现在逐像素相同；收纳书签的单项小菜单也相同（高度 `16 + row_h`，不画线）。

### 4. `tests/test_note_editing.py` — 新增 3 个测试
- `test_copy_all_puts_whole_note_on_clipboard_and_pastes_structure_into_another_note`
  文字行 + 未勾待办 + 已勾待办 + 空待办 → 剪贴板文字为 `"说明\n买牛奶\n已处理\n"`；另一张便签全选粘贴后 `d["lines"]` 与源一致；源便签不变；可撤销。
- `test_copy_all_includes_right_column_and_leaves_clipboard_alone_on_empty_note`
  双栏便签按左栏、右栏顺序复制；贴到单栏便签后行里没有 `mergedColumn`；空便签调用后剪贴板文字不变。
- `test_context_menu_offers_copy_all_as_fourth_row`
  右键某行，第 4 项为「复制全部内容」且点击后剪贴板更新；四项菜单高度 = 三项高度 + `row_h` + 9，四项都在画布内。
