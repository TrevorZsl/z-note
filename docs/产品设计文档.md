# z-note 产品设计文档

版本：V1.0（2026-10-26）
状态：待评审
平台：Windows 10 / 11（64 位）

---

## 1. 产品概述

**一句话定位**：一款常驻系统托盘的桌面便签工具，支持自由文本与可勾选待办混排、每张便签独立调节透明度和窗口层级（置底/正常/置顶），把桌面当白板用。

**目标用户**：希望在桌面上随手记事、贴待办清单，但又不想让便签占用任务栏、干扰正常窗口操作的用户。

**与 Windows 自带便笺的差异**：

| 能力 | Windows 便笺 | z-note |
|---|---|---|
| 任务栏占用 | 有 | 无，常驻系统托盘 |
| 透明度 | 不支持 | 每张便签独立调节 |
| 窗口层级 | 仅置顶 | 置底 / 置顶 两态切换 |
| 待办勾选+划线 | 仅纯文本加粗 | 原生复选框，勾选自动划线置灰 |
| 数据 | 账号云同步 | 纯本地 JSON |

**核心场景**：
1. 工作时把一张半透明的待办清单置底贴在桌面，随时可见但不挡任何窗口；
2. 临时想法 Ctrl+Alt+N 一秒弹出新便签，写完一勾了事；
3. 重启电脑后所有便签原样回到原位置，像没关过机一样。

---

## 2. 核心概念

- **便签（Note）**：一个独立的桌面浮动窗口。数量不限，每张独立记忆位置、大小、颜色、透明度、层级状态。
- **行（Line）**：便签内容的组成单位，两种类型：
  - **文本行**：普通文字；
  - **待办行**：带圆角复选框的条目，勾选后文字划线置灰（参考图风格）。
  - 任意一行可随时在两种类型间一键互转，文本与待办在同一张便签内自由混排。

## 3. 功能需求

### 3.1 便签窗口

- 新建便签：托盘菜单 / 全局快捷键 / 便签工具栏「+」按钮。
- 新便签默认出现在「当前活跃显示器的右上角」，多张新便签按 24px 阶梯错位层叠。
- 拖动：按住便签顶部区域拖动；缩放：右下角（或边缘）拖拽，最小尺寸 200×160。
- 关闭（×）：仅隐藏该便签到托盘，**不删除内容**；再次显示时从「便签列表」或「显示全部」恢复。
- 删除：工具栏「删除」按钮 → 弹确认对话框（防误删，数据不可恢复）。删除是唯一的永久移除方式。
- 便签底部统计条：`已完成 3/5`，右侧「清除已完成」文字按钮，一键清掉所有已勾选的待办行。

### 3.2 内容编辑

- **行操作**：
  - 行首 hover 出现 `☐/≡` 切换图标：文本行 ⇄ 待办行一键互转；
  - 待办行勾选后：文字加删除线、颜色置灰，复选框打勾（参考图样式）；
  - 行尾 hover 出现 `≡` 拖动手柄，拖动排序（所有行均可排序，不限待办行）；
  - 行尾 hover 出现 `×` 删除该行。
- **编辑体验**：
  - Enter 换行、Backspace 在行首向上合并，与普通编辑器一致；
  - Ctrl+Z / Ctrl+Y 撤销重做（单张便签内）；
  - 便签失焦自动保存（防抖 500ms），无「保存」按钮概念。
- **默认样式**：浅色简洁风格，圆角复选框，正文字号默认 14px（可在设置改默认值）。

### 3.3 窗口层级（置底 / 置顶 两态）

每张便签在两个状态间切换，工具栏「▼ 置底 / ▲ 置顶」两个按钮，当前状态高亮：

| 状态 | 行为 |
|---|---|
| **置底** | 永远沉在所有窗口之下，像贴在桌面上（类 Rainmeter）；点击它仍可直接编辑，但不会浮上来盖住别的窗口 |
| **置顶** | 永远在最前（如贴个密码/电话置顶用），新便签默认置顶 |

- 置底便签被全屏应用（游戏、视频全屏）覆盖是**预期行为**；
- 三态切换不影响透明度，两个维度独立。

### 3.4 透明度

- 每张便签独立调节 10%–100%，默认 95%；
- 工具栏透明度按钮 → 弹出滑杆（或 Ctrl+滚轮 在便签上快速调）；
- **可读性保护**：便签处于焦点编辑状态时，实际显示透明度临时提升至不低于 80%；失焦后恢复用户设定值。低透明度 + 置底时既能当背景水印看，点上去又能正常编辑。

### 3.5 系统托盘

- **最小化 / 关闭主程序窗口 = 缩到托盘**，不出现在任务栏（无任务栏按钮、不显示在 Alt+Tab）；
- 托盘图标：左键单击 = 新建便签（最高频动作）；
- 托盘右键菜单：

```
新建便签            Ctrl+Alt+N
显示/隐藏全部便签    Ctrl+Alt+H
──────────────
便签列表（最近 10 张，点击显示/隐藏）
──────────────
设置…
开机自启            ☑
──────────────
退出
```

- 「退出」是唯一真正结束进程的入口，退出前自动落盘。

### 3.6 设置窗口

从托盘右键「设置…」打开（普通窗口）。V1 设置项：

| 分组 | 设置项 | 默认值 |
|---|---|---|
| 常规 | 开机自启 | 开 |
| 常规 | 启动后立即显示便签 / 仅驻留托盘 | 立即显示 |
| 外观 | 新便签默认颜色（8 色板） | 淡黄 |
| 外观 | 新便签默认透明度 | 95% |
| 外观 | 新便签默认字号 | 14px |
| 快捷键 | 新建便签 / 显示隐藏全部（可改键） | Ctrl+Alt+N / Ctrl+Alt+H |
| 数据 | 打开数据文件夹 | — |

### 3.7 状态记忆与开机自启

- 所有运行时状态（每张便签的位置、大小、颜色、透明度、层级、内容，以及隐藏/可见）持久化，重启后**原样还原**；
- 自启通过注册表 `HKCU\...\Run` 或启动文件夹快捷方式实现（无需管理员权限）；
- 启动到可交互 < 1 秒（后台异步加载便签内容，先出托盘图标）。

### 3.8 全局快捷键

| 快捷键 | 动作 | 说明 |
|---|---|---|
| Ctrl+Alt+N | 新建便签 | 任何应用前台时可用 |
| Ctrl+Alt+H | 显示/隐藏全部便签 | 一键「收拾桌面」，隐藏只是不可见，不退出 |

- 快捷键冲突时设置页提示并要求换键；
- 快捷键可在设置中修改。

## 4. 数据设计

**纯本地存储，零账号、零联网。**

- 存储位置：`%APPDATA%\z-note\notes.json`（单文件，含全部便签与设置）；
- 写入时机：变更后防抖落盘 + 退出时落盘，双保险；
- 自动备份：每次启动将上一份数据文件复制为 `backup/notes.{N}.json`，滚动保留最近 20 份；
- 文件带 `schemaVersion` 字段，升级时向前迁移。

数据模型（示意）：

```jsonc
{
  "schemaVersion": 1,
  "settings": {
    "launchAtStartup": true,
    "showOnStartup": true,
    "defaultColor": "#FFF7C0",
    "defaultOpacity": 0.95,
    "defaultFontSize": 14,
    "hotkeys": { "newNote": "Ctrl+Alt+N", "toggleAll": "Ctrl+Alt+H" }
  },
  "notes": [
    {
      "id": "uuid",
      "rect": { "x": 1820, "y": 120, "width": 320, "height": 420 },
      "monitorId": "\\\\.\\DISPLAY1",
      "zState": "bottom",          // bottom | normal | top
      "opacity": 0.4,
      "color": "#FFF7C0",
      "visible": true,
      "createdAt": 1790000000000,
      "updatedAt": 1793000000000,
      "lines": [
        { "type": "text", "text": "本周重点" },
        { "type": "todo", "text": "跑通推理服务压测", "checked": true,  "doneAt": 1792900000000 },
        { "type": "todo", "text": "整理量化实验报告", "checked": false }
      ]
    }
  ]
}
```

**边界情况**：
- 便签所在的显示器已拔除/分辨率变化 → 启动与恢复时将便签位置夹回主显示器可见区域；
- 系统锁屏/睡眠恢复 → 不重排位置，仅校验可见性；
- 数据文件损坏 → 启动时提示并从最近备份恢复。

## 5. 非功能需求

| 项 | 目标 |
|---|---|
| 常驻内存 | < 100 MB |
| 空闲 CPU | ≈ 0%（置底钩子为事件驱动，非轮询） |
| 冷启动到托盘可用 | < 1 s |
| 安装形态 | 绿色单文件 exe 或轻量安装包，无运行时依赖捆绑优先 |
| 数据安全 | 任何崩溃不丢已落盘内容；删除有确认；自动备份 20 份 |

## 6. 技术选型建议

关键平台能力是托盘、整窗透明、**窗口置底**（Windows 无原生 always-on-bottom）、全局快捷键、开机自启。对比：

| 方案 | 托盘 | 透明 | 置底 | 内存 | 体积 | 备注 |
|---|---|---|---|---|---|---|
| **WPF（.NET，推荐）** | Hardcodet / Win32 | 原生 | Win32 直调，最顺 | 60–90 MB | 单文件自包含 | Win32 互操作零障碍，最适合常驻小工具 |
| Tauri 2 | 内置 | 整窗 alpha 可用 | Rust 侧 win32 crate 实现 | 80–120 MB | ~5 MB | 前端栈友好，置底/层级细节需自己磨 |
| Electron | 内置 | 可用 | 同需 Win32 | 200 MB+ | 80 MB+ | 常驻内存对便签工具过重，不推荐 |
| WinUI 3 | 需社区库 | 一般 | 可行 | 中 | 中 | 生态与发布链路仍偏折腾 |

**置底实现要点**（无论哪个栈）：`SetWinEventHook(EVENT_SYSTEM_FOREGROUND)` 监听前台窗口变化，对 bottom 态便签调 `SetWindowPos(HWND_BOTTOM)` 重新沉底；置顶用 `HWND_TOPMOST`；整窗透明用 `SetLayeredWindowAttribute(LWA_ALPHA)`。

**推荐结论**：WPF + Hardcodet.NotifyIcon.Wpf，发布为自包含单文件。若团队更熟 Web 栈，Tauri 2 为次选。

## 7. 版本规划

**V1（本文档范围）**：托盘常驻、便签窗口、文本+待办混排勾选划线、行拖动排序、三态层级、透明度、设置窗口、开机自启+状态记忆、全局快捷键、本地存储+自动备份。

**V2 候选（按优先级）**：
1. 待办到期提醒（托盘闪烁 + 系统通知）；
2. 点击穿透模式（低透明度铺桌面当背景清单，鼠标完全穿透）；
3. 数据导出/导入（换机迁移）；
4. 便签管理主窗口（便签多时的列表/搜索/归档）。

**远期**：云同步（WebDAV/账号）、富文本、多主题皮肤。

## 8. 验收清单（对照原始需求）

- [ ] 主窗口最小化/关闭后仅驻留系统托盘，任务栏无按钮、Alt+Tab 不可见（需求 1）
- [ ] 每张便签透明度 10%–100% 独立可调，聚焦编辑时自动提升可读性（需求 2）
- [ ] 每张便签可独立置底/置顶两态切换；置底时始终在所有普通窗口之下且可直接编辑（需求 2）
- [ ] 任意行可转待办行，勾选后划线置灰，支持拖动排序与清除已完成（需求 3）
- [ ] 托盘右键菜单含：新建、显示/隐藏全部、设置、开机自启开关、退出；设置窗口可改默认外观与快捷键（需求 4）
- [ ] 重启后全部便签（含位置/大小/层级/透明度）原样还原（附加需求）
- [ ] Ctrl+Alt+N / Ctrl+Alt+H 全局快捷键可用且可修改（附加需求）
- [ ] 断电/崩溃后已落盘内容不丢失，备份可恢复（数据安全）
