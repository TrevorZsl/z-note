# Icons

Source: Lucide (https://github.com/lucide-icons/lucide), as showcased by Morphicons (https://www.morphicons.com/).

Original SVGs and license are included. PNGs are rendered at 64 px from the SVGs using Sharp, with currentColor set to #6B7280 (normal), #9B968D (pin), or #1F2328 (active pin). Tkinter displays them at 18 px, or 20 px for the add-todo plus.

Mapping: pin = toggle always-on-top; sticky-note = new note; trash = delete note; minus = hide note; plus = add todo.
