# Icons

Source: Lucide (https://github.com/lucide-icons/lucide), as showcased by Morphicons (https://www.morphicons.com/).

Original SVGs and license are included. PNGs are rendered at 64 px from the SVGs using Sharp, then recolored to #4B5563 (normal), #736D64 (pin), #1F2328 (active pin), or #2B2F36 (add-todo plus). Tkinter displays them at 22 px, or 26 px for the add-todo plus.

Mapping: pin = toggle always-on-top; sticky-note = new note; trash = delete note; minus = hide note; plus = add todo.
