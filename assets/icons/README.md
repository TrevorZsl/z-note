# Icons

Source: Lucide (https://github.com/lucide-icons/lucide), as showcased by Morphicons (https://www.morphicons.com/).

Original SVGs and license are included. PNGs are rendered at 64 px from the SVGs using Sharp, then recolored to #4B5563 (normal), #736D64 (pin), or #1F2328 (active pin). Tkinter displays them at 22 px, or 26 px for the add-todo plus.

Mapping: pin = toggle always-on-top; plus = new note / add todo; trash = delete note; minus = hide note.
